# TODO Scheduler (Планировщик задач)

## Описание проекта

Это веб-приложение для управления списком задач (TODO-листом). Реализован бэкенд на Go и фронтенд на HTML/CSS/JS. Приложение позволяет:
*   Просматривать список предстоящих задач.
*   Добавлять новые задачи с возможностью установки правил повторения (ежедневно, еженедельно, ежемесячно, ежегодно).
*   Редактировать существующие задачи.
*   Отмечать задачи как выполненные (с автоматическим переносом даты для повторяющихся задач).
*   Удалять задачи.
*   Искать задачи по заголовку, комментарию или дате.

Сервер использует базу данных SQLite для хранения задач и предоставляет REST API для взаимодействия с фронтендом.

## Список выполненных заданий со звёздочкой

Реализованы все задания со звездочкой:

✅ **Определение порта сервера через переменную окружения** - Сервер использует порт из переменной `TODO_PORT`

✅ **Определение пути к файлу БД через переменную окружения** - Путь к базе данных задаётся через переменную `TODO_DBFILE`

✅ **Реализация всех правил повторения** - Поддерживаются правила `d`, `y`, `w` и `m` для вычисления следующей даты выполнения задачи

✅ **Реализация поиска задач** - Обработчик `/api/tasks` поддерживает параметр `search` для фильтрации по тексту (в названии или комментарии) и по дате в формате `DD.MM.YYYY`

✅ **Аутентификация** - Реализована простая аутентификация по паролю. Пароль задаётся в переменной окружения `TODO_PASSWORD`. Используются JWT-токены, хранящиеся в cookie

✅ **Docker** - Проект упакован в Docker-образ для удобства развёртывания

## Инструкция по запуску (локально)

### Требования
*   Установленный Go (версия 1.23 рекомендуется)
*   Установленный Git
*   Установленный Docker (версия 28.3.2 рекомендуется)

### Шаги для запуска

1.  Клонируйте репозиторий (или распакуйте архив с проектом):
    ```bash
    git clone <your-repo-url>
    cd go_final_project
    ```

2.  (Опционально) Установите переменные окружения. Вы можете задать их прямо в командной строки или создать файл `.env`:
    
    **Linux/macOS:**
    ```bash
    export TODO_PORT=7540
    export TODO_DBFILE="./scheduler.db"
    export TODO_PASSWORD="my_secret_password"
    ```
    
3.  Соберите и запустите сервер:
    ```bash
    go build -o scheduler .
    ./scheduler
    ```

4.  Откройте браузер и перейдите по адресу: `http://localhost:7540` (порт может быть другим, если вы меняли `TODO_PORT`).

5.  Если вы задали пароль (`TODO_PASSWORD`), вас перенаправит на страницу входа (`/login.html`). Введите пароль для доступа к приложению.

## Инструкция по запуску тестов

1.  Убедитесь, что ваш сервер **не запущен** на том же порту, который указан в настройках тестов.
2.  Перейдите в корневую директорию проекта.
3.  Запустите все тесты следующей командой:
    ```bash
    go test ./tests
    ```

**Настройки тестов** (файл `tests/settings.go`):
*   Порт сервера: `7540`
*   Путь к файлу БД: `../scheduler.db` (относительно директории `tests`)
*   `FullNextDate: true` (так как реализованы все правила)
*   `Search: true` (так как реализован поиск)

> Для тестов с аутентификацией необходимо вручную установить переменную `Token` в `settings.go`, получив его от запущенного сервера через запрос к `/api/signin`.

## Инструкция по сборке и запуску через Docker

### Сборка образа

1.  В корневой директории проекта (где находятся `Dockerfile`, `main.go` и директория `web`) выполните команду:
    ```bash
    docker build -t scheduler:v1 .
    ```

### Запуск контейнера

Для запуска контейнера используется команда `docker run`. Важно пробросить порт и подключить volume с файлом базы данных, чтобы данные сохранялись после остановки контейнера.

**Пример команды для запуска (Linux/macOS):**
```bash
docker run -d \
  -p 7540:7540 \
  -v $(pwd)/scheduler.db:/data/scheduler.db \
  -e TODO_PORT=7540 \
  -e TODO_DBFILE="/data/scheduler.db" \
  -e TODO_PASSWORD="my_password" \
  --name scheduler-app \
  scheduler:v1
